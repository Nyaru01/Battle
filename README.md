# Battle

`Battle` est le nom de travail d'un jeu mobile de stratégie en arène, en temps réel, destiné à Android. Le projet reprend les codes du genre — deck, énergie, déploiement d'unités et parties courtes — avec un univers, des règles, une interface et des contenus originaux.

## État du projet

Le dépôt contient actuellement le cadrage de production du MVP. Le développement n'a pas encore commencé.

- [Plan de développement](docs/PLAN_DEVELOPPEMENT.md)
- Cible initiale : APK Android
- Mode prioritaire : duel classé 1 contre 1
- Modèle réseau : serveur autoritaire
- Moteur proposé : Unity, version LTS stable au démarrage de la production

## Prochaine décision

Valider le périmètre du MVP, la direction artistique et la composition de l'équipe, puis lancer la phase 0 décrite dans le plan.
